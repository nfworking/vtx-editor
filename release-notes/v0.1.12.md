# Vantrex 0.1.12

## New

- **Release notes after an update.** The first time Vantrex starts after an update, it opens these notes in a tab so you can see what changed. Turn it off with the checkbox at the bottom of the tab, or the `update.showReleaseNotes` setting. You can reopen them any time from **Help > Show Release Notes**.

## Improved

- **A simpler About dialog.** It now shows only the Vantrex version, the build date and your operating system.
- **Updates install reliably.** The updater now starts its installer before Vantrex quits and cleans up after itself, so "Restart to Update" finishes the job.

## Upgrade notes

Updating from 0.1.11 will not open this tab, because that version does not yet remember which release it last ran. From the next update on, the notes open automatically.
