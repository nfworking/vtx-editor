# Vantrex 0.1.13

## New

- **A welcome flow.** The first time you open Vantrex, the window itself starts small and clean on native Liquid Glass (macOS 26 with Metal), and walks you through picking a look, build notifications, signing in and what Vantrex can do. When you finish, the window grows into the editor. Replay it any time with **Vantrex: Show Welcome Flow**.
- **Two new themes.** **Vantrex Light**, and **Vantrex Liquid Glass**, which turns the whole window into frosted glass. Set how see-through it is with **Vantrex: Set Window Transparency…**. On older Macs and on Windows it falls back to the older blurred material; on Linux it stays solid.
- **Source Control for Vantrex workspaces.** A workspace now has its own Source Control view: your changed files, a side-by-side view of each change, discard, and a **Commit & Push** button that sends your changes to GitHub on this branch or a new one, with an optional pull request.
- **Open Database Project.** A new command opens a database project straight from the command palette, and the project picker always lists databases. When there are none, or they can't be reached, it now says why.

## Fixed

- **Signing out now closes the workspace.** Before, a workspace you had open stayed readable after you signed out. Now the files stop loading, and the window leaves the workspace.
- The built-in Vantrex features no longer ask for permission to use your Vantrex account.
