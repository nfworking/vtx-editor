# Vantrex 0.1.14

## Changed

- **A new look that matches the platform.** The Vantrex Dark and Vantrex Light themes are now neutral black and white with hairline borders, the same look as the Vantrex dashboard. The orange accent is gone, and the interface uses the Geist font.
- **The Vantrex Liquid Glass theme has been removed.** If you were using it, the editor switches to Vantrex Dark. The welcome flow still opens on native Liquid Glass.
- A cleaner command bar, welcome flow and Vantrex logo.
- Database tools and the workspace preview got small fixes.
